## SAP Developers Beware: Malicious Packages Hijack Credentials in Supply Chain Attack

A sophisticated supply chain attack is currently targeting developers working with SAP's JavaScript ecosystem, silently stealing sensitive credentials. Researchers have uncovered a campaign dubbed "mini Shai-Hulud" that injected malicious code into legitimate-looking npm packages, putting developer machines and cloud environments at risk.

### The Deceptive Packages Unmasked

Several widely used npm packages crucial for SAP application development have been compromised. According to cybersecurity firms Aikido Security, SafeDep, Socket, StepSecurity, and Google-owned Wiz, specific versions of `mbt`, `@cap-js/db-service`, `@cap-js/postgres`, and `@cap-js/sqlite` were found to contain hidden malicious behavior. These compromised releases, published on April 29, 2026, between 09:55 and 12:14 UTC, introduced an unexpected "preinstall" script. This script, disguised as part of the package setup, downloaded and executed a malicious Bun JavaScript runtime from GitHub, bypassing security checks and potentially granting attackers unfettered access.

### Stealthy Credential Harvesting in Action

The insidious nature of this attack lies in its ability to operate stealthily. The "setup.mjs" script, triggered upon installation, acts as a sophisticated loader for the credential-stealing malware. This malware is meticulously designed to pilfer a wide range of sensitive information directly from developer environments and CI/CD pipelines. This includes local developer credentials, tokens for both GitHub and npm, secrets stored within GitHub Actions, and critical cloud credentials for major providers like AWS, Azure, and GCP, as well as Kubernetes secrets. The exfiltrated data is then encrypted and covertly sent to newly created public GitHub repositories, often originating from the victim's own account and bearing the ominous description, "A Mini Shai-Hulud has Appeared."

### A Familiar Shadow: Tracing the Threat Actor

Intriguingly, Wiz researchers have observed that the malicious techniques employed in the "mini Shai-Hulud" campaign bear a striking resemblance to previous operations attributed to "TeamPCP." This strong correlation suggests that the same threat actor is likely responsible for this latest wave of attacks, indicating a persistent and evolving threat within the software supply chain. The attackers' ability to compromise legitimate packages and leverage developer tools for their own nefarious purposes underscores the escalating sophistication of cyber threats in the modern development landscape.

### What To Watch

Developers utilizing the affected SAP-related npm packages should immediately verify their installed versions and, if compromised, initiate incident response protocols. Keeping a close eye on security advisories from npm and SAP, as well as cybersecurity research firms, will be crucial in identifying any further threats or new indicators of compromise. Vigilance in scrutinizing package dependencies and employing robust security scanning tools are now more critical than ever for protecting development environments.
