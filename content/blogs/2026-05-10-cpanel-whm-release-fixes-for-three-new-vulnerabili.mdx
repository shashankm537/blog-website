## Security Alert: cPanel and WHM Address Critical Vulnerabilities – Act Now!

Web hosting professionals and server administrators, take note: cPanel and Web Host Manager (WHM) have just rolled out crucial updates to patch three newly identified security flaws. These vulnerabilities, if left unaddressed, could have allowed attackers to gain unauthorized access, execute malicious code, or even disrupt server operations.

### Understanding the Threats: What's Been Fixed?

The vulnerabilities addressed span several critical areas within the cPanel and WHM platforms. One significant issue, carrying a moderate CVSS score of 4.3, involved an oversight in how file names were handled, potentially enabling attackers to read sensitive files they shouldn't have access to. More concerning are two other vulnerabilities, both with a higher CVSS score of 8.8. These could have allowed authenticated users to execute arbitrary Perl code, essentially giving an attacker the ability to run commands on the server, or to manipulate file permissions through unsafe symbolic link handling, leading to denial-of-service attacks or escalating privileges.

### Essential Updates: Version Numbers and Where to Find Them

The good news is that cPanel has been proactive in releasing patches for these threats. Administrators are urged to update their systems to the following versions or higher: cPanel and WHM versions 11.136.0.9, 11.134.0.25, 11.132.0.31, 11.130.0.22, 11.126.0.58, 11.124.0.37, 11.118.0.66, 11.110.0.116, 11.110.0.117, 11.102.0.41, 11.94.0.30, and 11.86.0.43. Additionally, WP Squared users should ensure they are on version 11.136.1.10 or above. For those still running older operating systems like CentOS 6 or CloudLinux 6, a specific update, cPanel version 110.0.114, has been provided as a direct upgrade.

### What To Watch

While cPanel has confirmed no widespread exploitation of these vulnerabilities has been detected, the timing of this disclosure, just days after another critical flaw was revealed, underscores the importance of vigilance. Server administrators should prioritize applying these patches immediately to safeguard their systems. Keep an eye on official cPanel and WHM security advisories for any further updates or intelligence regarding these or other emerging threats.
