## Developers Beware: Another Checkmarx Plugin Targeted in Fresh Supply Chain Attack

Just weeks after a major supply chain incident, Checkmarx is once again in the cybersecurity spotlight. Threat actors have successfully compromised a popular Jenkins plugin, raising alarms about the integrity of developer tools and the ongoing risks within the software supply chain.

### A Familiar Foe Strikes Again

The cybersecurity firm Checkmarx has confirmed that a malicious version of its Jenkins AST (Application Security Testing) plugin was deliberately published to the official Jenkins Marketplace. This incident marks another attack orchestrated by the group known as TeamPCP, which was recently linked to a significant compromise involving Checkmarx's KICS tool, two VS Code extensions, and a GitHub Actions workflow. Those earlier attacks were designed to steal developer credentials, highlighting a pattern of targeting tools trusted by software development teams.

### How the Attack Unfolded

Security researchers have detailed a concerning method of infiltration, suggesting that TeamPCP gained unauthorized access to the plugin's GitHub repository. The repository's name was reportedly altered to a highly provocative "Checkmarx-Fully-Hacked-by-TeamPCP-and-Their-Customers-Should-Cancel-Now," and its description ominously stated, "Checkmarx fails to rotate secrets again." This defacement not only served as a taunt but also as a clear indicator of the attackers' intent and access level. The fact that TeamPCP has managed to breach Checkmarx systems again so soon suggests either incomplete security fixes from the previous incident or the persistent presence of an undetected foothold.

### What To Watch

Developers utilizing the Checkmarx Jenkins AST plugin are urged to immediately verify they are running version 2.0.13-829.vc72453fa_1c16 or an earlier, unaffected version. Checkmarx has released a newer version, 2.0.13-848.v76e89de8a_053, and is continuing to update its security measures. The cybersecurity community will be closely monitoring Checkmarx's ongoing investigation into how the malicious code was introduced and assessing the effectiveness of their remediation efforts to prevent future breaches of this nature. This latest incident underscores the critical need for robust security practices and vigilance across the entire software development lifecycle.
