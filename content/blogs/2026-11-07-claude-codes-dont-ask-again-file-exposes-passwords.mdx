## AI Assistant Accidentally Exposes Sensitive Developer Secrets

A popular AI coding assistant, Claude Code, has inadvertently exposed thousands of developer passwords and API keys, leaving them vulnerable in publicly accessible code repositories. The oversight, discovered by security researchers, stems from a feature designed to streamline coding workflows but which can, in certain configurations, store sensitive information in plain text.

### How Secrets Found Their Way Online

The issue lies within Claude Code's "Don't Ask Again" feature. When developers choose to bypass future prompts for executing commands, the AI assistant can save these commands, including any embedded credentials, directly into a project's settings file. This file, identified as `.claude/settings.local.json`, can then be inadvertently committed to public repositories like GitHub. Researchers from Apiiro have identified over 1,100 public copies of this file containing at least one exposed secret, raising significant security concerns for developers worldwide.

While Claude Code attempts to prevent this file from being tracked by Git in the first place by adding it to global git excludes, this protection is local to a single user's machine. It doesn't retroactively secure files that have already been committed to a repository. This means that even if the file is removed from a project, older versions containing leaked secrets can persist in the repository's history and in any forks.

### Widespread Risk and Immediate Concerns

The implications of these exposed credentials are far-reaching. Sensitive API keys and passwords, if still active, could grant unauthorized access to cloud services, databases, or other critical infrastructure. While Apiiro did not confirm the validity of all the discovered keys, one company they alerted did verify that a leaked key was indeed still functional. This underscores the real-world risk to organizations whose developers utilize this feature without proper precautions.

The security firm recommends an immediate rotation of all passwords, tokens, and keys that may have been stored in the `.claude/settings.local.json` file. Following this, developers should meticulously clean up any compromised files from their repositories to mitigate further risk.

### What To Watch

Developers using Claude Code should review their project settings and repository histories for any instances of the `.claude/settings.local.json` file. Expect potential updates from Anthropic addressing this vulnerability, and heightened scrutiny from security professionals regarding AI assistant integrations in software development workflows.
