# PHP Races to Patch Critical 'PHP2Shell' Flaws Amidst Leak and Emergency Release

PHP is issuing an out-of-cycle security update today, October 21st, to address two critical vulnerabilities that pose a significant remote code execution risk. The emergency release comes after a leak of information about the flaws, prompting PHP to accelerate its patching timeline to protect users.

## Critical Flaws Revealed and Accelerated Patching

Security researchers have confirmed the existence of two severe vulnerabilities within PHP, now being dubbed 'PHP2Shell' by the security community. These flaws carry a high severity rating of 9.2 on the CVSS v4.0 scale, indicating a substantial risk of exploitation. While the exact technical details remain under wraps until the official release, the vulnerabilities are known to allow attackers to execute arbitrary code on affected systems. Only the most recent supported versions of PHP, from 8.2 to 8.5, will receive the critical patch.

## Leak Prompts Disclosure and Security Scramble

The swift action by PHP was reportedly triggered by a leak of information on October 20th, which detailed the existence of these two remote code execution vulnerabilities. While the initial leak claimed a CVSS score of 10.0 and affected a broad range of PHP versions from 5 onwards, this information was based on unverified sources. Security firm watchTowr later confirmed the leak's authenticity and the impending disclosure, urging caution. PHP's own advisory acknowledges the possibility of an earlier release if details become public or active exploitation is detected, underscoring the urgency of the situation.

## What To Watch

Users of PHP versions 8.2 through 8.5 should be prepared to apply the security update as soon as it becomes available later today. The full technical details of the vulnerabilities, along with the precise list of affected and patched versions, will be disclosed by PHP alongside the release. This will be crucial for organizations to assess their immediate risk and plan their patching strategy effectively.
